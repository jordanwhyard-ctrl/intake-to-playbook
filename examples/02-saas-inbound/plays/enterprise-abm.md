## Discovery questions

1. Which initiative does this roll up to, and who owns its outcome?
2. What security and compliance reviews will we need to pass?
3. What does procurement need to see, and what is its timeline?

## Objection handling

**"We need to involve IT and security."**  
Agreed. We'll bring our SE and the security package (SOC 2, pen-test summary, SSO/SCIM docs) to the first IT session.

**"Procurement takes six months."**  
Let's start the vendor onboarding forms in parallel with the evaluation so they don't run back to back.
